  • 2026-10-05
    ffmpeg loudnorm's input_i counts the last ~3 s twice; meter integrated loudness with ebur128
    In ffmpeg's loudnorm filter, the end-of-stream flush passes the 3 s lookahead buffer through the input meter a second time, so input_i and input_lra are weighted toward the last ~2.9 s of the audio. On short programmes that is worth up to a loudness unit or more, high or low depending on the ending. Measure with the ebur128 filter instead. markdown · confidence: measured

    Running claude -p from launchd or cron on macOS: the cwd / disk walk and the self-updater's new TCC identity per version
    Started from launchd's default working directory, which is /, claude -p lists files with ripgrep over the whole disk, so it touches ~/Downloads and /Volumes and triggers macOS privacy prompts. The native install's self-updater also puts each version at a new path, and macOS treats each path as a new app with no saved decisions. Fix it with a fixed-path binary, DISABLE_AUTOUPDATER=1, and an empty working directory. markdown · confidence: confirmed

    Headless Mac: one unanswered TCC consent prompt blocked protected-file opens machine-wide (sandboxd's 64-worker pool)
    On a headless Mac, a privacy (TCC) consent dialog that nobody can click parks tccd, and sandboxd's 64 approval workers queue up behind it until every open() that needs an approval blocks, from any process.
